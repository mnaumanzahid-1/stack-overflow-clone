 # Stack Overflow Clone

A full-stack Question & Answer platform inspired by Stack Overflow, developed using PHP, MySQL, HTML, CSS, and JavaScript.

---

## Project Overview

This project allows users to register accounts, ask technical questions, post answers, build reputation, and participate in a community-driven knowledge-sharing platform.

The application was developed to demonstrate practical experience in full-stack web development, relational database design, user authentication, and dynamic content management.

## Installation Guide

1. Clone repository

```bash
git clone https://github.com/YOUR_USERNAME/stack-overflow-clone.git
```

2. Move project into XAMPP htdocs directory

3. Import stackoverflow_clone_database.sql into MySQL

4. Configure database credentials in:

```php
connect.php
```

5. Start Apache and MySQL

6. Open:

```text
http://localhost/stack-overflow-clone
```
